## 유지한 결정

B 세리프 워드마크를 유지한다. 비교 페이지와 보드는 `../logo-options.png`의 실제 B 영역을 SVG viewport로 표시한다. 워드마크를 새 폰트로 대체하거나 재생성하지 않았다. B 워드마크는 여전히 래스터 원본이며, 새 앱 심벌 6종만 순수 벡터이다.

이전 선택인 Fold는 기준안으로 보존한다. 이번 6개 후보는 아직 최종 선택하지 않았으며 제품 앱의 로고 파일은 교체하지 않았다.

## 발상과 구조

| 번호 | 이름 | 발상 | 구조 |
|---|---|---|---|
| 01 | Unfold | 하루를 여는 틈 | 접힌 두 면의 비대칭 기하 |
| 02 | Gather | 흩어진 이야기가 하나로 | 크기와 방향이 다른 캡슐 모듈 |
| 03 | Cadence | 문장이 소리가 되는 결 | 같은 방향으로 접히는 평행 곡선 |
| 04 | Daymark | 오늘을 찍는 한 점 | 열린 원형과 독립된 점 |
| 05 | Interleaf | 행간에서 만나는 맥락 | 겹친 두 면과 음각의 교차점 |
| 06 | Swift | 소식을 건네는 종이새 | 종이와 새로 읽히는 두 면 |

추천 비교 대상은 05와 06이다. 05는 추상적인 편집 브랜드, 06은 전달이라는 의미가 있는 상징 방향이다. 01은 기존 Fold에 가장 가까운 발전안이다.

## 스킬 적용 범위

스킬의 여섯 방향 비교, 간결한 기본 요소, 여백, 비대칭, `viewBox="0 0 100 100"`, `currentColor` 원칙을 적용했다. 모바일 아이콘에서 알아볼 수 있는 크기를 확보하기 위해 예제의 작은 점 군집은 큰 캡슐 모듈로, 복잡한 네트워크는 두 면의 관계로 줄였다. 템플릿의 헤더·시안 그리드·설명·정교화·다운로드 구조를 가져와 프로젝트의 로컬 폰트와 순수 HTML/CSS/JS로 구성했다.

이 단계는 새 심벌 선택 전의 비교 단계다. 선택 이후에 해당하는 4개 분위기 목업/Gemini API 단계는 실행하지 않았다. 이번 결과는 직접 작성한 SVG이며 이미지 생성 모델의 결과를 벡터라고 표시한 것이 아니다. PNG는 동일 SVG를 sharp로 렌더링했다. 제공된 `svg_to_png.py`는 CairoSVG 의존성이 없어 사용하지 않았으며, 설치되어 있는 sharp를 사용했다.

## 파일과 기능

- `assets/`: 심벌 SVG 6개, 블루·사각 앱 아이콘 SVG 6개, 각 아이콘의 16/24/32/64/1024px PNG 30개.
- `comparison.svg`: 모든 시안의 비교 보드. B 워드마크를 보존하기 위한 래스터 참조만 포함한다.
- `comparison.png`: 1500×1160px 보드.
- `web-preview.png`: 브라우저의 실제 전체 페이지 스크린샷.
- `build.py`: SVG·보드·HTML의 단일 생성 소스.
- `template.html`, `style.css`, `script.js`: 스킬 템플릿 구조를 적용한 비교 UI.
- `render.cjs`: sharp를 통한 PNG 내보내기.

흑백/블루, 사각/원형 마스크, 후보 담기와 필터, B 워드마크 조합, SVG·PNG 다운로드를 제공한다. 비교 선택은 `briefly-symbol-round03-shortlist` 로컬 저장소 키에만 기록된다. 다운로드 앱 아이콘은 블루·사각 기준이며 최종 플랫폼 배포 패키지가 아니다.

## 검수

- 브라우저 폭 1440px에서 3열, 390px 및 320px에서 모바일 표시 확인.
- 320px 페이지와 상세 팝업에서 가로 넘침 없음. 소형 화면의 128px 샘플은 다음 줄에 표시.
- 표시된 소형 아이콘의 실제 CSS 폭 16/24/32/64px 확인.
- 흑백·원형 전환, 후보 05/06 담기 및 필터, 상세 조합 보기, Escape 닫기 확인. 검수용 선택은 해제했다.
- 브라우저 경고·오류 로그 없음. JS 구문 검사 통과.
- SVG 12개 파싱 및 viewBox 확인, PNG 30개의 실제 해상도 확인.
- HTML/CSS/JS/보드/대표 SVG/1024 PNG의 HTTP 200 확인.
- 16px에서 세부적인 종이/새 의미는 단순한 실루엣으로 읽힌다. 최종 선택 후 실제 홈 화면과 파비콘 맥락에서 추가 조정할 수 있다.

## 재생성

`python build.py` 실행 후 `node render.cjs`를 실행한다. sharp는 Node 모듈로 설치되어 있거나 환경변수 `BRIEFLY_SHARP_PATH`가 해당 패키지 경로를 가리켜야 한다. 프로젝트를 수정하는 별도 외부 API 키는 필요하지 않다.

비교 페이지는 `../../serve.py --port 8770`으로 실행되는 프로토타입 서버에서 연다. 원형 마스크 및 흑백은 비교 UI의 표시 설정이며 파일 생성 상태와 구분된다.
