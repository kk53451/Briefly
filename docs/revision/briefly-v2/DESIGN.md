# Briefly — BI & Product System v0.3

2026-10-23. 확정한 Softpress 워드마크와 한 줄 앱 아이콘을 기준으로 정리한 모바일 우선 시스템. 로고 선택은 확정이며 제품 화면은 가상 콘텐츠로 검토하는 HTML 프로토타입이다.

## 브랜드 기준

**복잡한 하루에, 짧고 선명한 맥락.**

시간이 부족해도 세상과 연결되고 싶은 사람을 위한 짧은 데일리 브리핑. 한 회차의 세 이야기를 읽거나 듣고 끝낼 수 있는 경험을 만든다.

- 성격: 부드러운 편집자. 둥근 로고에서 친근함을, 내용의 위계와 출처에서 신뢰를 만든다.
- 이름: 항상 **Briefly**. 대문자 B와 소문자 riefly. 02 Softpress 벡터의 획·비례·자간을 유지한다.
- 앱 아이콘: 한 줄 Briefly. 글자 채움 면적의 세로 중심을 50/100에 맞춘 확정 자산. 두 줄·B.는 이전 탐색이다.
- 색상: 기본 블루, 흰색 반전, 검정 단색. 임의의 기울기·늘림·그림자·심벌 결합을 사용하지 않는다.
- 여백: 워드마크 전체 높이의 ¼ 이상. 헤더 너비 122–140px, 최소 권장 110px. 앱 아이콘의 글자 판독은 48px 이상에서 검토한다.
- 문장: ‘전체 듣기’, ‘읽기 시작’, ‘이어서 읽기’, ‘출처 확인’. 과장된 긴급함이나 사실 검증 완료를 암시하지 않는다.

## 시각 계획과 사전 검토

로고의 둥근 활자를 모든 한글 제목에 흉내 내는 대신, 로고와 회차 표지에 성격을 집중한다. UI는 Pretendard와 넉넉한 행간으로 읽는다. 전체 화면을 카드로 나누는 초기 접근을 버리고 회차만 한 장의 표지로 묶으며, 이야기는 열린 목록으로 이어간다.

기존의 반복 로고, 큰 안내 문구와 장식적 표지를 줄였다. 코발트 회차에는 오늘의 주제와 실제 재생 순서인 세 구간만 남긴다. 바로 아래 두 버튼은 읽기·듣기의 진입점이다. 읽기 진행은 사용자가 ‘읽고 다음으로’ 또는 ‘다 읽었어요’를 선택한 이야기만 센다.

```text
모바일 390px                     웹 1440px
가상 뉴스 미리보기                 로고 / 오늘 / 보관함 / 지난 회차
Briefly                 지난 회차  오늘의 브리핑 / 날짜
날짜 · 오전판                     ┌ 회차 표지 ┐  이야기 01
오늘의 브리핑                     │ 구간 1–3 │  이야기 02
┌ 코발트 회차 ────────────────┐   └───────────┘  이야기 03
│ 오늘의 주제 / 짧은 맥락       │   듣기 / 읽기    완료 표시
│ 01 경제 · 02 사회 · 03 기술   │   읽기 진행
└────────────────────────────┘
[전체 듣기 5:12] [읽기 시작 2분]
읽기 진행 0/3
이야기별로 살펴보기
01 경제 / 제목 / 요약 / 출처·듣기
하단: 오늘 / 보관함 / 지난 회차
```

본문과 제목은 왼쪽 정렬한다. 모바일에서 듣기·읽기는 첫 화면 안에 들어오며 첫 이야기 제목이 함께 보인다. 웹은 같은 위계를 두 열로 확장한다.

## 디자인 토큰

원본은 `tokens.json`, 배포본은 `tokens.css`. `build_tokens.py`로 생성한다.

| 색 | 값 | 용도 |
|---|---|---|
| Paper | #FFFFFF | 읽기와 기본 화면 |
| Mist | #F5F7FC | 배경·상태·기기 미리보기 |
| Ink | #192137 | 제목·본문·플레이어 |
| Blue | #244BEB | 로고·회차·주요 행동 |
| Slate | #616A7C | 보조 정보 |
| Tint | #EDF1FF | 보조 행동·선택 배경 |

성공·오류는 의미에만 쓰며 색과 텍스트를 함께 제공한다. Peach는 현재 시스템에서 제거했다.

| 역할 | 모바일 / 웹 | 무게·행간 |
|---|---|---|
| 브랜드 | 확정 Fraunces 윤곽선 | 재조판 금지 |
| 화면 제목 | 30 / 42px | 680 · 1.25 |
| 회차 제목 | 29 / 36px | 650 · 1.28 |
| 이야기 제목 | 21 / 24px | 630 · 1.4 |
| 본문 | 15 / 16px, 상세 18px | 430 · 1.7–1.8 |
| 메타·라벨 | 12–13px | 500 · 1.5 |
| 버튼 | 14–15px | 650 · 최소 높이 52px |

간격은 4/8/12/16/20/24/32/40/48/64px. 모바일 가로 여백 22px, 360px 이하는 18px. 최대 콘텐츠 폭 1180px. 곡률은 컨트롤 16px, 회차·대화상자 28px, 상태 칩은 pill. 그림자는 떠 있는 플레이어·대화상자에만 쓴다. 최소 터치 영역은 44px. 포커스는 3px 외곽선, 브랜드 표지 위에서는 흰색이다. reduced-motion을 존중한다.

## 상태와 핵심 흐름

| 요소 | 동작과 상태 |
|---|---|
| 회차 | 날짜·발행 시각·3개 이야기. 재생 구간은 실제 이야기 순서를 나타낸다. |
| 듣기 | 시작·일시정지·이어서 듣기. 구간 버튼은 해당 이야기 시작점으로 이동. |
| 읽기 | 처음·이어서 읽기·다시 읽기. 마지막 열었던 이야기를 이 브라우저에 기억. |
| 읽음 표시 | 명시적 완료 행동으로 누적. 3개가 모두 완료됐을 때만 회차 완독. |
| 이야기 | 제목 읽기, 출처, 해당 구간 듣기, 저장. 읽음 표시는 텍스트와 기호 병기. |
| 보관함 | 저장·해제·빈 상태. 이 브라우저에만 저장된다는 설명 유지. |
| 읽기 상세 | 현재 이야기 위치, 이전·다음·완료, 출처 왕복, Escape·닫기. |
| 미니 플레이어 | 현재 구간·시간·재생/정지·현재 구간 읽기·닫기. 실제 음원 없는 미리보기임을 표시. |
| 불러오기 실패·오디오 준비 중 | 시스템 가이드에서 별도 예시. 존재하지 않는 데이터를 성공 상태로 표시하지 않음. |

## 구현 경계

로컬 BI·디자인 시스템과 반응형 HTML UX를 다듬는다. Flutter 교체·백엔드·음원 생성·배포는 하지 않는다. 날짜 2026-10-23의 가상 회차이며 시사 정보가 아니다. 회차 분량(3개 이야기·2분 읽기·5분 듣기)은 초기 제품 가설이다. 출처 예시는 실제 기사나 검증 완료를 의미하지 않는다.
