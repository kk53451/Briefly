# v0.3 검수 기록

2026-10-23. 로컬 Chromium 기반 브라우저에서 확인했다. 실제 기기·스크린리더 인증은 아니다.

## 화면

- 제품: 320×780, 390×844, 1440×1000에서 문서 가로 넘침 없음.
- 가이드: 320px·390px·1440px에서 문서 가로 넘침 없음. 320px의 간격·곡률 예시가 넘치던 문제를 수정했다.
- 모바일 390px에서 읽기·듣기 버튼 하단은 537px, 첫 이야기 제목 하단은 762px, 하단 내비게이션 시작은 770px로 확인했다.
- 회차 구간 버튼 44px 높이, 주요 읽기·듣기 버튼 61px 높이, 지난 회차 버튼 44×44px.
- 읽기 창: 320px에서 너비 320px, 내부 가로 넘침 없음. 브라우저 기본 dialog max-width로 우측에 여백이 생기던 부분을 수정했다.
- 모든 주요 이미지 로드 확인. HTML 템플릿 치환 완료, 연결된 정적 자산 11개 HTTP 200.

## 동작

- 첫 이야기 ‘읽고 다음으로’ → 1/3 읽음 → 닫고 새로고침 → 두 번째 이야기 ‘이어서 읽기’ 유지.
- 세 이야기 완료 → 3/3 및 ‘오늘의 브리핑 완독’, ‘다시 읽기’ 표시.
- 초기화 후 마지막 이야기만 완료 → 1/3, 마지막 이야기만 읽음. 회차 전체 완료로 처리하지 않음.
- 출처 열기 → 이야기로 돌아가기에서 같은 이야기 유지.
- 사회 이야기 저장 → 보관함에 표시 → 저장 해제. 검수 전 저장 상태로 복구.
- 사회 구간 듣기 → 1:44 시작, 사회 구간 선택 상태와 미니 플레이어 일치.
- 일시정지 → 메인 버튼이 ‘이어서 듣기’로 변경. 플레이어에서 읽기 → 현재 사회 이야기 열기.
- 읽기 Escape 닫기, 플레이어 닫기, 가이드 저장 피드백 확인.
- 가이드 모바일·웹 전환 및 검토용 읽기 초기화 확인. 최종 미리보기의 읽기 상태는 0/3으로 복구.
- app.js, system.js 구문 검사 통과.
